## 작성 지침

- 각 질문과 답변을 함께 보고, 사용자의 답변 경향을 종합하세요.
- 답변이 "사용자 답변 안 함"인 항목은 사용자가 해당 질문에 답변하지 않은 것으로 간주하세요.
- 사용자가 답변하지 않은 질문은 unansweredGuidance에 반드시 포함하세요.
- unansweredGuidance에는 해당 질문의 핵심 의도와, 사용자가 어떤 프로젝트 경험/기술 판단/문제 해결 과정 순서로 답변하면 좋을지 작성하세요.
- 미답변 항목은 improvements에도 반영하되, 비난하지 말고 보완 방향으로 작성하세요.
- 답변이 있는 항목은 구체성, 구조, 질문 관련성, 기술 키워드 사용 여부를 기준으로 strengths와 improvements에 반영하세요.
- nextActions에는 사용자가 다음 면접 연습에서 바로 실행할 수 있는 구체적인 행동을 작성하세요.
