## 작성 지침

- 답변에서 잘한 점을 먼저 언급하세요.
- 구체성이 부족하면: 수치, 시간, 건수 등 정량적 표현을 추가하도록 안내하세요.
- 구조가 부족하면: 상황 → 내가 한 행동 → 결과 순서로 재구성하도록 안내하세요.
- 기술 키워드가 부족하면: 답변 주제와 관련된 기술 용어 1~2개를 구체적으로 제시하세요.

- 코드에서 확인되지 않는 내용을 사용자가 주장한 경우:

## 응답 형식

반드시 아래 JSON 형식만 반환하세요.
설명 문장, 마크다운, 번호 목록을 절대 포함하지 마세요.

{
  "scores": {
    "structure":   1~5,
    "relevance":   1~5,
    "keyword":     1~5,
    "specificity": 1~5
  },
  "feedback": "답변 개선을 위한 피드백 한 단락 (150자 이상 300자 이하)",
  "warning":  "코드에서 확인되지 않는 내용 주장 시 명시, 없으면 null"
}

점수 기준 (각 1~5점):
- structure:   상황-행동-결과 흐름이 있는가
- relevance:   질문의 핵심에 직접 답하고 있는가
- keyword:     기술 면접에 적합한 용어가 사용되었는가
- specificity: 수치, 사례, 상황이 포함되어 있는가
