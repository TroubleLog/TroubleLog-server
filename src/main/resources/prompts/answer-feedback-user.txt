## 작성 지침

- specificity: 수치, 시간, 건수 같은 정량 표현이 있으면 높게, 없으면 낮게 평가하세요.
- structure: 상황, 행동, 결과 흐름이 자연스럽게 드러나면 높게 평가하세요.
- relevance: 질문이 묻는 핵심에 직접 답하고 있으면 높게 평가하세요.
- keyword: 트랜잭션, 동시성, 단일 책임 원칙 같은 기술 용어를 적절히 사용하면 높게 평가하세요.

improvement 작성 규칙:
- 4점 미만 항목이 있을 때만 작성하세요.
- 개선 방향은 구체적으로 1~3문장 사이로 작성하세요.
- 모든 점수가 4점 이상이면 문자열 "null"이 아니라 JSON null 리터럴을 반환하세요.
- warning이 없으면 문자열 "null"이 아니라 JSON null 리터럴을 반환하세요.
